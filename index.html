    How this site is built

    Horizon Atlas is a static site hosted on GitHub Pages — plain HTML, CSS, and JavaScript with no server of its own. Antinode provides the BaaS layer: Google sign-in, encrypted secrets vault, Google Drive upload for visitors, hosted account & billing, and the amAIra chat embed you can open after signing in.
